# 多语言实施与验证（2026-10-20）

本次完成原作语言选择面板的11种语言，保留现有陶瓷界面和玩法。原作枚举中的意大利语、德语、印地语不在本次范围。

## 已实现行为

- 列表顺序为 English、Русский、한국어、日本語、Indonesia、Français、Español、Português、العربية、简体中文、繁體中文。内部语言码统一为 `en_US / ru / ko_KR / ja / id / fr / es / pt / ar / zh_CN / zh_TW`。
- 已保存选择优先，兼容旧 `zh`、`en`。没有有效选择时单次异步查询 YouTube `system.getLanguage()`，2秒超时；独立运行、异常、超时及不支持的语种回退英文。设备语言不参与默认选择。自动检测不写入手动偏好，也不覆盖查询期间的手动选择。
- 支持连字符、下划线、大小写和地区变体；中文含 `TW` 或 `Hant` 选繁体，其余中文选简体；`in`、`ms` 映射印尼语。
- 设置显示语言原名，独立滚动弹窗选择后立即保存并返回设置。X/Esc取消不改变选择；支持鼠标、触摸拖动和键盘焦点环绕，遮罩阻止操作背后的界面。
- 使用 Godot 翻译变更通知刷新动态提示、教程、槽位提示、计时、结果和纪录，保留选关页、盘面节点、选中硬币、教程步骤和计时。浏览完成关纪录不会覆盖另一关的进行中存档。
- 锁关说明使用含等级参数的完整句子，并保留独立硬币图示。长文案按整形后的行数和字体高度适配。
- 阿拉伯语使用RTL及连写整形，棋盘和分页保持现有方向，数字计时保持LTR。紧凑时长分段隔离，避免分钟、秒钟单位错序。简繁中文使用中文标志，其余语种使用英文标志。
- 共享设置场景统一使用绘制层级30，设置和语言弹窗位于选中硬币及玩法特效之上；关闭后保留选中状态。节点顺序调整继续保证输入遮挡。

## 翻译、字体和运行依赖

`translations/menu.csv` 保留原有110个键，扩展为11种语言。中文和英文保留现有文案，其余语言优先复用本地保存的原作对应译文，并补齐项目新增说明和格式化句子。生成工具检查缺项、替换字符及参数类型和顺序，Godot导入时解码换行。

`tools/build_translations.py` 使用的原作快照是离线构建输入。运行时仅加载11个 `menu.*.translation`，缺失键或语言资源回退英文，不读取参考资料目录或原Cocos资源。

字体使用 Noto Sans、Noto Sans SC/TC/JP/KR 和 Noto Sans Arabic 六组650字重静态子集，通过 `CoinMergeUI.tres` 组合。各字体禁用操作系统字体回退，保留阿拉伯语OpenType整形特性；原生语言名称和译文均有随包字形。许可证、来源和SHA-256保存在 `assets/reskin/ceramic/fonts/`。全量字体下载保留在忽略提交的缓存，字体构建工具保留源时间戳以便重复构建。
